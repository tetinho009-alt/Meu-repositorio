# Post · TikTok

Regras em `metodo/capa-e-post.md`. Texto curto (2 a 3 linhas), 3 a 5 hashtags específicas.

## Modelo

```
[Série] · Parte [N]. [Gancho em uma frase.]
[Ação 1] ou [ação 2]? A maioria decide a Parte [N+1].
Ficção.
#[genero] #[tema] #[genero2] #[serie]
```

## Exemplo preenchido (série fictícia)

```
O Último Ônibus · Parte 1. Oito passageiros onde antes eram sete.
Descia no ponto ou ficava no ônibus? A maioria decide a Parte 2.
Ficção.
#terror #historiadeterror #suspense #oultimoonibus
```

## Configuração

- Capa: um quadro forte do vídeo (o relance da ameaça, o rosto na janela), escolhido no app ou por
  `video_cover_timestamp_ms` no envio por rascunho.
- Rótulo de IA: só se houver plano fotorrealista ou voz que imita pessoa real (`metodo/seguranca.md`).
- Não marcar como conteúdo só para adultos.
- Publicação: agendador do TikTok Studio no computador (até 10 dias) ou rascunho pela API e publicação no app.

## Comentário fixado

```
Parte [N+1] sai [dia] às [hora]. Placar e ordem dos episódios: no perfil (sem URL no fixado; o link fica só na bio).
```
