# Esqueleto de viral

Copie para `canal/virais/<nome-curto>.md`, um arquivo por viral estudado. Este arquivo é estudo seu: ele não vai
para o vídeo, para a legenda nem para outra pessoa.

```
viral: <nome curto que você dá>
onde: <rede e @ do perfil>
link: <link do post>
visto em: <data> com <views no dia> views
formato: <você / terceira pessoa> · <duração> · <série? qual parte?>
```

## Anotação

Escreva o que você ouviu, com as suas palavras ou colando a legenda que o próprio post mostra. Não baixe o vídeo de
outro perfil: o texto anotado já basta para tirar o esqueleto.
