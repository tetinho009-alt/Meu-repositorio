# Temporada Viral só no celular

Pelo celular, você usa o Claude Code na nuvem: é o mesmo Claude Code do computador, rodando numa máquina na internet
que você controla pelo app do Claude. A IA faz roteiro, voz, imagens e montagem, e o vídeo pronto fica guardado para
você baixar. Na nuvem não tem placa de vídeo, então o vídeo demora mais do que no computador. O 3D sai pelo Three.js, que desenha
só com o processador.

## O que você precisa

- O plano **Pro** do Claude (pago). Sem ele, o caminho é pelo computador: veja `LEIA-ME.md`.
- Uma conta no **GitHub**, que é grátis.
- A senha da área de membros (está na descrição da aula do celular).

**O que é o GitHub e o que é repositório:** o GitHub é um site que guarda pastas na internet. Cada pasta lá se chama
**repositório**. Pense numa pasta do Google Drive: o Claude usa essa pasta para guardar a ferramenta e os vídeos
prontos, e você entra nela pelo celular para baixar. Você cria a pasta uma vez só e usa sempre a mesma.

## 1. Crie a conta no GitHub

1. Abra o navegador do celular (Chrome ou Safari) e entre em **github.com**.
2. Toque em **Sign up**.
3. Coloque o seu e-mail e toque em **Continue**.
4. Crie uma senha e toque em **Continue**.
5. Escolha um nome de usuário (qualquer um, por exemplo `seunome-canal`) e toque em **Continue**.
6. Resolva o quebra-cabeça que prova que você não é robô.
7. O GitHub manda um código de 8 números para o seu e-mail. Abra o e-mail, copie o código e cole no GitHub.
8. Se aparecerem perguntas sobre você (equipe, interesses), toque em **Continue** ou pule até a tela inicial.

## 2. Crie a pasta (o repositório)

1. No navegador, já com a conta aberta, entre em **github.com/new**.
2. Em **Repository name**, escreva `meu-canal`.
3. Deixe a descrição em branco.
4. Marque **Private**, para só você ver.
5. Se aparecer a opção **Add a README file**, marque.
6. Desça a tela e toque no botão verde **Create repository**.

## 3. Ligue o Claude ao GitHub

1. Abra o app do Claude e toque na aba **Code**.
2. Na primeira vez, ele pede para conectar o GitHub. Toque em conectar.
3. Abre a página do GitHub pedindo permissão: toque em **Authorize**.
4. Se ele perguntar quais repositórios liberar, escolha **Only select repositories**, selecione `meu-canal` e toque
   em **Install**.
5. Volte ao app do Claude, escolha o repositório `meu-canal` e abra uma sessão nova.

## 4. Instale a Temporada Viral

1. Na caixa de mensagem da sessão, cole esta frase inteira, trocando pela senha da área de membros:

   ```
   Instale a Temporada Viral seguindo https://raw.githubusercontent.com/andrefranceschini/temporada-viral-instalador/main/INSTALAR.md
   A senha é: (a senha da área de membros)
   ```

2. Mande e espere: a IA instala sozinha, em alguns minutos.
3. Ela pede o e-mail que você usou na compra, para ativar a licença. Mande o mesmo e-mail.
4. Depois, ela faz perguntas sobre o seu canal, uma por vez, cada uma com duas sugestões. Responda ou escolha uma.

## 5. Faça e baixe o vídeo

1. Quando as perguntas acabarem, mande **nova série**.
2. A IA mostra cada etapa e só segue quando você manda **aprovado**.
3. No fim, ela diz o nome da pasta onde o vídeo ficou, uma pasta para cada rede.
4. Para baixar: abra **github.com** no navegador, toque em `meu-canal`, entre na pasta que a IA falou, toque no vídeo
   e depois no botão de download (a seta para baixo).

Da próxima vez, é só abrir o app do Claude, entrar em **Code**, escolher `meu-canal` e pedir o próximo vídeo.

Travou em qualquer passo? Mande um print da tela para a IA, ou fale com o suporte pelos comentários da área de membros
ou em contato@temporadaviral.com.
